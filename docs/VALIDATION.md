## 已执行的检查

`npm run check` 通过，包括 Prettier、ESLint、严格 TypeScript、10 项单元测试和生产构建。
`npm run test:e2e` 的 7 项真实浏览器测试通过：

1. 两颗独立星球生成、渲染并完成往返跃迁。
2. 延迟目标下载时，动画继续，玩家不提前抵达。
3. 取消跃迁后，出发位置保持不变。
4. 普通航行到另一颗地表，无跃迁和坐标跳变；持续向地面飞行仍停留在地表上方约 8 米。
5. 生成代码实际尝试联网，被阻止，且没有 DOM。
6. 无限循环的生成器超时终止，主站仍可操作。
7. 等长篡改的源码无法通过 SHA-256 校验。

连续飞行测试将星球间距缩短，以便快速回归；使用生产相同的控制器、坐标、加载和地表检测。
真实星图中心距离约 81 km，可按住 W 与 Shift 持续飞行，或选中后跃迁。
